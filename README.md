# Шахабиддин — Портфолио

Жеке портфолио сайты (HTML, CSS, JavaScript).

## Түзүм

```
shahabiddin-portfolio/
├── index.html
├── README.md
├── css/style.css
├── js/script.js
└── assets/images/
    ├── ustaz.jpeg
    ├── choco-fontan.jpeg
    ├── abulayt.jpeg
    └── great-trade-company.png
```

## Иштетүү

`index.html` файлын браузерде ачыңыз. Сүрөттөрдү `assets/images/` папкасына жогорудагы аттар менен салыңыз.

## Эмнени өзгөртүү керек

- `index.html` ичиндеги «Мен жөнүндө» текстин жана долбоорлордун сүрөттөмөлөрүн өзүңүздүкүнө алмаштырыңыз.
- Статистика сандарын өзгөртүү үчүн `data-count` маанилерин оңдоңуз.
- Түстөр `css/style.css` башындагы `:root` бөлүгүндө турат.
- Байланыш формасы азырынча билдирүүнү эч жакка жөнөтпөйт, ал үчүн сервер же Formspree сыяктуу кызмат керек.
